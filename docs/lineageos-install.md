# Встановлення LineageOS на SM-T505 (фаза 1)

Джерела: офіційні шаблони вікі LineageOS для `gta4l` (`before_recovery_install_samsung_qcom`, `recovery_install_samloader_rs`), сторінка завантажень `download.lineageos.org/devices/gta4l`, README samloader-rs. Перевірено 2026-11-19.

> ⚠ Кроки 4–8 незворотні: розблокування завантажувача стирає всі дані й назавжди змінює стан Knox. Ви це погодили 2026-11-19, резервні копії зроблено.

**Хто що робить.** Кнопки й екран планшета — **ви**. Команди на ПК — **я**. Після кожного кроку звіряємося, лише потім переходимо до наступного.

LineageOS 24.0 — це Android 17, патч безпеки 2026-11-01, щотижневі nightly-збірки. Google-сервісів (GApps) не ставимо: для дашборда вони не потрібні, а WebView у LineageOS оновлюється разом із системою.

## Крок 0. Зняти акаунти й батьківський контроль (ви)

Батьківський контроль або корпоративне керування стає «власником профілю» і може заборонити скидання до заводських (`no_factory_reset`). Тоді перемикач «OEM unlock» неактивний. До того ж, поки на пристрої є Google-акаунт, захист FRP від Samsung блокує прошивку неофіційних образів.

1. Налаштування → Облікові записи та резервне копіювання → Керування обліковими записами → кожен Google-акаунт → **Видалити обліковий запис**.
2. Якщо на планшеті є батьківський контроль чи інший застосунок керування, зніміть його в самому застосунку або на пристрої, з якого ним керують.
3. Якщо є Samsung-акаунт, видаліть і його.
4. Перевірте через adb, що власників більше немає: `adb shell dpm list-owners` виводить `no owners`.
5. Перевірте, що заборона скидання зникла: `adb shell dumpsys user | findstr no_factory_reset` нічого не виводить (команду на цьому кроці не запускали).

## Крок 1. Оновлення стокової прошивки (необов'язково, ви)

Налаштування → Оновлення ПЗ → Завантажити й установити. Вікі вимагає, щоб перед встановленням був Android 12 — він у нас уже є. Свіжіша стокова прошивка оновлює також модем і завантажувач, які LineageOS потім використовує.

## Крок 2. Увімкнути OEM unlock (ви)

1. Під'єднатися до Wi-Fi.
2. Налаштування → Відомості про планшет → Відомості про ПЗ → 7 разів натиснути «Номер збірки».
3. Параметри розробника → **OEM unlock** (Розблокування OEM) → увімкнути.
   - Якщо перемикача немає, скажіть мені. На Samsung він іноді з'являється лише після того, як пристрій побув у мережі.

## Крок 3. Підготовка ПК (я)

- Завантажити й перевірити файли з таблиці вище.
- `samloader detect` у режимі Download. Драйвери Samsung уже встановлені (у системі є «SAMSUNG Mobile USB Modem»). Якщо стандартний USB-бекенд не побачить планшет, використовуємо `--usb-backend vcom`.

## Крок 4. Розблокування завантажувача (ви) — стирає дані

1. Вимкнути планшет.
2. Затиснути **Гучність− і Гучність+** одночасно й, не відпускаючи, під'єднати USB-кабель до ПК → з'явиться синій екран попередження.
3. **Довго натиснути Гучність+** («Device unlock mode») → підтвердити ще раз **Гучність+**.
4. Планшет зітре дані й перезавантажиться в стоковий Android.
5. Пройти налаштування, **пропускаючи все** (без акаунтів), під'єднатися до Wi-Fi.
6. Знову увімкнути параметри розробника й переконатися, що **OEM unlock увімкнено** (перемикач може бути сірим — це нормально).

## Крок 5. Прошивка vbmeta (ви + я)

1. Вимкнути → знову режим Download (Гучність− + Гучність+ + кабель) → коротко **Гучність+** («Continue»).
2. Я запускаю: `samloader flash --partition VBMETA vbmeta.img`
3. Планшет перезавантажиться й **вимагатиме скидання** — виконати за підказками на екрані.
4. Знову пройти налаштування без акаунтів, Wi-Fi, перевірити, що **OEM unlock увімкнено**.

## Крок 6. Lineage Recovery (ви + я)

1. Вимкнути → режим Download → **Гучність+** («Continue»), кабель під'єднано.
2. Я запускаю: `samloader flash --partition RECOVERY recovery.img --no-reboot`
3. На планшеті з'явиться смуга передачі, потім напис `Downloading... Do not turn off target!!` — він лишається на екрані, це нормально.
4. **Одразу** затиснути **Гучність− + Живлення** на 8–10 с. Щойно екран згасне, **миттєво** відпустити й затиснути **Гучність+ + Живлення** (кабель під'єднано) → має з'явитися Lineage Recovery.
   - Якщо завантажився стоковий Android, він уже перезаписав recovery — повторюємо крок 6.

## Крок 7. Встановлення LineageOS (ви + я)

1. У Lineage Recovery: **Factory reset → Format data / factory reset** → підтвердити.
2. Повернутися назад → **Apply update → Apply from ADB**.
3. Я запускаю: `adb -d sideload lineage-24.0-20261115-nightly-gta4l-signed.zip`
   - Зупинка на ~47% з повідомленням `Total xfer: 1.00x` — це нормальне завершення.
4. На питання про встановлення додатків (add-ons) відповісти **No**: GApps не потрібні.
5. **Reboot system now**. Перше завантаження триває до 10 хв.

## Крок 8. Перше налаштування LineageOS (ви + я)

1. Мова, Wi-Fi, **без** блокування екрана, без акаунтів.
2. Налаштування → Про планшет → 7 разів «Номер збірки» → Параметри розробника → **USB-налагодження** → підтвердити ключ ПК.
3. Я перевіряю через adb: `ro.build.type`, версію WebView, користувачів і акаунти, стан заряду.
4. Налаштування → Акумулятор → **Charging control** → обмеження заряду (наприклад, 80%). Для `gta4l` LineageOS це підтримує: заряджання вимикається через `batt_slate_mode`.

Після цього переходимо до тесту правої половини (claude.ai у WebView) і до фаз 2–4.

## Якщо щось пішло не так

- **Не входить у Download:** вимкнути повністю; затиснути Гучність− і Гучність+ **до** під'єднання кабелю; спробувати інший кабель або порт.
- **«Custom binary blocked by FRP lock»:** на пристрої лишився Google-акаунт → повернутися до кроку 0.
- **Бутлуп після кроку 7:** у recovery ще раз виконати Format data, потім sideload.
- **Повернення на стокову прошивку:** можливе через `samloader download` + `samloader flash` (офіційна прошивка SM-T505, CSC AUT). Knox при цьому лишиться «підпаленим».
